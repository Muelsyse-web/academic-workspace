# 独立审查与修复记录

2026-10-13。多名独立子代理分别进行规格与代码质量检查；主任务复现问题、补回归、修复并集成。最终验证：307 后端、23 前端、3 条完整浏览器流程，详见根目录 ACCEPTANCE.md。

## 已修复的确认问题

| 范围 | 发现 | 修复及回归 |
|---|---|---|
| 上传 | 限制在 multipart 落盘后才生效 | ASGI 接收预算，覆盖 Content-Length 与分块请求；前端按文件数/字节分批 |
| 去重/来源 | 错扩展名无法恢复、存储哈希误作标题 | 失败导入允许修正格式；真实短标题和文件名回退，手工标题不被重建覆盖 |
| 搜索 | 全库截断挤掉范围内结果、SQL 参数数溢出 | 数据库内 FTS CTE、范围限制及分页；原 32,766 候选复现已通过 |
| 中文 | 连续汉字的空格查询/自然问句遗漏 | 字符片段索引与查询展开，单字/短词/完整问题回归 |
| UI 搜索 | 改筛选后加载更多混入旧结果 | 清空旧页，加载期间禁止重叠请求 |
| 会话 | 新标签页轮换 cookie 导致旧页 CSRF 失效 | 复用有效会话；过期/恢复后前端只重连重试一次 |
| 笔记 | 删除后静默链接同名替代笔记、歧义无法人工选择 | 删除目标 tombstone、显式绑定接口与 UI，绑定经重命名仍保留 |
| 笔记 UI | 多文档引用入口缺失、新建时异步清空新草稿 | 来源选择器和真实摘录校验；取消旧加载/避免重复重置，浏览器复现已修复 |
| 复习 | Quiz 缺少编辑 | 事务性 PATCH，题目更换仍保留旧答题快照 |
| AI | 模型配置与 transport 读取竞态 | 统一配置/凭据/transport 快照 |
| 向量 | 索引期间来源版本变化却发布失效结果 | 固定源 ID 集合，提交前验证代次；失败保留旧索引 |
| 排序 | BM25、余弦及 fallback 混用分值 | 对合并候选使用一致的 RRF 相关度尺度 |
| 取消 | 只标记取消但等完整请求返回 | 异步 HTTP 任务取消并关闭 socket；真实 loopback 慢响应回归 |
| 恢复 | 旧密钥残留、manifest 不计预算、活动请求竞态 | 回滚保护的凭据移出、统一预算、完整请求生命周期的独占恢复入口 |
| 便携数据 | 无任务的处理中资料、错误历史评分可导入 | 标为需重试；依据历史题目快照重新校验评分与答案 |
| 渲染 | 远端 Markdown 图片可能自动请求 | 显示替代文本，不自动抓取外部图像；脚本/危险 URL 回归 |
| 日志 | 第三方 PDF 警告暴露输入片段 | pypdf 诊断隔离、仅保留脱敏错误类别；UTC 轮换日志 |
| 导出/Provider | 异常 ID 进入 ZIP 路径、响应先无限读后限长 | 安全文件名与流式预算，详见安全报告 |
